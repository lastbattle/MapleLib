## GMS v270 dossier

### Role

`MapleStory.exe` has a normal PE import from this DLL, so the loader brings it in as a direct dependency. The only statically imported GameScale symbol recorded for the executable is `EndDiscordCall`; the SDK exports 150 functions, mostly in its `social` namespace. Together with the product strings, this identifies the module as the GameScale SDK integration layer for Nexon services and Discord, not primarily a window-resolution or image-scaling component. It also implements a WebView2-based UI/overlay host. The static evidence does not identify it as an anti-cheat component.
