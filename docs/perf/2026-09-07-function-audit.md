## What one row means

Each row maps an explicit or source-derived callable to its file, start/end line and column, namespace, containing type, subsystem, and callable kind. Kinds distinguish methods, constructors, operators, conversion operators, delegates, local functions, lambdas, and individual `get`, `set`, `init`, `add`, and `remove` accessors. `Origin` distinguishes explicit syntax, expression-bodied accessors, field-event accessors, and the inactive `UOLRES` branch.

`InitialClassification` is automated triage only:

- `candidate`: syntax contains a loop, a hot-path-like operation name, or a nontrivial body in crypto/serialization.
- `requires-workload`: nontrivial implementation whose importance cannot be inferred without real call frequency and inputs.
- `trivial`: short body or short/automatic accessor. This does not prove that a frequently invoked function is irrelevant.
- `contract-only`: declaration has no source body, such as an interface member or delegate signature.

All rows begin with `MeasurementStatus=not-measured`. An `AuditStatus` of `source-reviewed` means a human/agent inspected the source; it does not mean that a benchmark found a speedup. An `AuditStatus` of `unreviewed` is intentional and keeps the remaining audit scope visible.

## Preprocessor coverage

The active syntax pass honors source `#define` directives and uses the default (non-`DEBUG`) parse options. The only conditional compilation that changes callable declarations is `WzUOLProperty.cs`: it defines `UOLRES`, while its `#else` declares a fallback `GetString()`. The generator performs a second syntax pass with that file-local symbol disabled and adds the inactive declaration with `Origin=conditional-inactive-UOLRES`. The remaining `DEBUG` directives only change statements inside already-listed method bodies; they do not add or remove callable declarations.

The ledger covers source declarations and source-derived accessor/event functions. It deliberately does not fabricate compiler-generated members with no declaration location, such as default constructors, record equality members, async/iterator state-machine methods, closure classes, or delegate `BeginInvoke` machinery. Such generated code should be attributed to its source callable during profiling.

## Reproduction

From the repository root, run:

```powershell
& MapleLib/docs/perf/generate-function-inventory.ps1
```

The generator only parses source and writes the CSV. It does not build projects, run tests, or execute benchmarks. Regenerate after source edits; line locations and IDs are snapshot identifiers and can shift when declarations move.
